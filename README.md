# ELENA.OS // The Living Archive

An interactive, fixed-viewport portfolio built as a rain-soaked field terminal. The archive presents Elena Chrysaki's products, technical projects, research, AI skills, commissioned websites, artistic experiments and GitHub activity as applications inside a recovered computer system.

## Enter the archive

The production site is designed for `https://elchrysaki.github.io`.

```bash
npm install
npm run dev
```

Create an optimized static build with:

```bash
npm run build
```

GitHub Actions publishes the `dist/` artifact to GitHub Pages whenever `main` changes.

## Current transmissions

- **OffMap** — a student-powered opportunity map and open-source community hub.
- **EUROAVIA App** — a private community platform with profiles, onboarding, local groups and a forum.
- **AeroPet** — an ESP32-C3 flight-tracking Tamagotchi with BLE and a Flutter companion app.
- **Commit Greenhouse** — public GitHub push activity advances a cybernetic plant through twelve growth stages.

The interface supports mouse, touch and keyboard. Press `1` through `8` to open applications and `Esc` to close the current window.
